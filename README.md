# Indonesia's Renewable Energy Transition: EDA Progress and Challenges

## Project Title and SDG Focus
* **Project Title:** Indonesia's Renewable Energy Transition: An Exploratory Data Analysis of Progress and Challenges
* **SDG Focus:** SDG 7: Affordable and Clean Energy

## Dataset Description
This project utilizes data sourced from the **Handbook of Energy and Economic Statistics of Indonesia 2024** by the Ministry of Energy and Mineral Resources (ESDM). The dataset covers:
- Macro indicators (GDP, Population, Household).
- Energy supply and consumption (Coal, Oil, Natural Gas, Renewables).
- Power plant performance (Installed capacity, fuel mix, PLN vs IPP generation).
- Environmental impact (GHG emissions).

## How to Run
1. Ensure you have Python installed (3.9+ recommended).
2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
3. Open the Jupyter Notebook eda_analysis.ipynb using Jupyter Lab, Jupyter Notebook, or Google Colab.
4. Update the file paths in the read_csv or read_excel functions if you are running this locally.
5. Run all cells to generate the analysis and visualizations.
